# 桌面摸鱼阅读器

上班摸鱼用的 txt 悬浮阅读器：透明、置顶、可拖动、可缩放，不进任务栏。

## 运行方式

用 **IDEA（JetBrains）** 打开本目录，右键 `reader_tk.py` → **Run** 即可。
解释器需为 Anaconda 的 `python3.10`（已自带 tkinter，零第三方依赖）。

> 不需要打包 exe，也不需要改文件关联。

## 基本操作

| 操作 | 方法 |
| --- | --- |
| 打开文件 | 拖入窗口，或菜单「文件 → 打开」 |
| 移动窗口 | 按住 **Alt + 左键** 拖动 |
| 缩放窗口 | 拖右下角 |
| 滚动 | 普通滚轮 |
| 调字号 | **Ctrl + 滚轮** |
| 调透明度 | **Alt + 滚轮** |
| 自动滚动 | 空格 |
| 搜索 | **Ctrl + F**（F3 下一个） |
| 章节目录 | **Ctrl + T** |
| 老板键（隐身/显示） | **Ctrl + Alt + H** |

## 说明

- 窗口位置、字号、主题、透明度、每本书阅读进度，自动存到
  `%APPDATA%\ZhuoMianYueDuQi\config.json`。
- 四种主题：深夜 / 浅色 / 米黄 / 护眼绿（菜单切换）。
- 开机自启：菜单「选项 → 开机自启」。
- 贴边隐藏：拖到屏幕左右边缘自动收起，鼠标移上去弹回（菜单可开关）。
